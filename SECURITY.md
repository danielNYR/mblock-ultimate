# Seguridad

## Versiones con soporte

Solo la versión más reciente recibe correcciones de seguridad.

## Reportar una vulnerabilidad

**No abras un issue público.** Si encuentras una falla, por ejemplo una forma de que un sitio:

- evada la protección de redirecciones;
- lea datos de la extensión;
- inyecte CSS o código a través de una lista de filtros;

repórtala de forma privada desde la pestaña **Security → Report a vulnerability** del repositorio.

Incluye la versión de la extensión y de Firefox, los pasos para reproducirla y, si es posible, una página de prueba. Recibirás una respuesta en un plazo de 7 días. Te mantendremos informado y te daremos crédito en el CHANGELOG si lo deseas.
